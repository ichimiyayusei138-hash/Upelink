# 五度圏ハーモニーラボ

十二平均律の12音を五度圏の順（C → G → D → A → E → B → F♯ → D♭ → A♭ → E♭ → B♭ → F）に色相環へ30°ずつ割り当て、
**ベース・和音・トップ**の3声部をそれぞれ別の五度圏図で同時に光らせるツールです。`index.html` をブラウザで開くだけで動きます（ビルド不要）。

## 3声部
- **和音**：コード進行。中音域で、声部の動きが最小になる転回を自動で選んで伴奏します（白玉／4分刻み／アルペジオ）
- **トップ／ベース**：和音とは独立した旋律。各音の音名・オクターブ・長さ（0.125拍単位で自由）を和音の区切りと関係なく設定できます
- 五度圏図：和音は構成音を多角形で、旋律は直前の音からの動きを矢印付きの軌跡で表示し、音程（例：「D5 から 長2度下」）も表示

## 編集
- アレンジ画面（トップ／和音／ベースの3段、拍で揃った横スクロール）で音や和音を選んで編集
- 旋律の音：音名（その時点の和音の構成音を太枠表示）、オクターブ・半音の上下、長さ、休符、分割、移動、複製、削除
- PCキー（A〜K）で選択中の音の後ろにステップ入力
- 和音：パレット（ダイアトニック／借用・セカンダリードミナントなど、強進行の印つき）、根音・種類・拍数・オンコード表記
- テキスト入力：和音 `FM7 E7 Am7 Gm7:2 C7:2`、旋律 `E5:1.5 D5:0.5 C5 r:1 A4:2`
- テンプレート（小室進行など9種と「もう恋なんてしない」のサビ前・サビ）、キーごと移調、声部ごとのミュート、元に戻す、マイ進行の保存（ブラウザの localStorage）
