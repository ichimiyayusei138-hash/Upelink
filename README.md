# 五度圏ピアノロール

十二平均律の12音を五度圏の順（C → G → D → A → E → B → F♯ → D♭ → A♭ → E♭ → B♭ → F）に色相環へ30°ずつ割り当てたピアノロールです。鳴っている鍵だけが自分の色でグローします。

`index.html` をブラウザで開くだけで動きます（ビルド不要）。

- 鍵盤やロールの段をクリック／タップ、または PC キーボード（A〜K、Z/X でオクターブ移動）で演奏
- 小室進行・王道進行・カノン進行・Just the Two of Us 進行・イチロクニーゴー・アクシス進行・ツーファイブワン・アンダルシア進行・12小節ブルースを自動再生
- キー（12調）、テンポ、弾き方（白玉／4分刻み／アルペジオ）を変更可能
- 鳴っている音を五度圏ホイール上に多角形で表示
